HOW TO UPDATE F1 UNIVERSE TRACKER
=================================

Your leagues, logins and passwords are NOT stored in this folder. They live in
%LOCALAPPDATA%\F1UniverseTracker, so replacing the program files never touches them.

EASY WAY
1. Close the black tracker window.
2. Double-click update.bat. It downloads the newest version and installs it here.
3. Double-click run_lan.bat (or run.bat) again.

BY HAND
1. Close the black tracker window.
2. Download the ZIP from https://github.com/MrManWho/F1Database (Code > Download ZIP).
3. Drag everything from the extracted folder into this folder and choose
   "Replace the files in the destination". Keep the .venv folder that's already here.
4. Double-click run_lan.bat (or run.bat) again.

Anyone who was logged in stays logged in - they may just need to refresh.
If an update changes the save format, each league is backed up automatically to
%LOCALAPPDATA%\F1UniverseTracker\backups before anything is changed.
New Python packages install themselves the next time you launch.
